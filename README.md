*** Chạy API demo
    - Mở terminal và chạy lệnh: npx json-server db.json

*** Cách cài đặt:
    - Vào chrome://extensions/
    - Bật "Developer mode"
    - Giải nén file zip "auto_fill_extension.zip"
    - Kéo thả thư mục "auto_fill_extension" vào trang extensions
    - Hoặc click "Load unpacked" và chọn thư mục đã giải nén
